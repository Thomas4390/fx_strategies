# 02 — Event Handlers MQL5

Chaque EA est piloté par des événements. Cette page liste les handlers disponibles,
leur timing, et quand utiliser quoi.

## Matrice quand-utiliser-quoi

| Besoin | Handler |
|--------|---------|
| Réagir à chaque tick du symbole chart | `OnTick` |
| Tâche périodique (refresh data, monitoring DD) | `OnTimer` |
| Détecter un fill / close de position | `OnTradeTransaction` |
| Réagir à un clic / touche utilisateur | `OnChartEvent` |
| Init / cleanup | `OnInit` / `OnDeinit` |

## OnInit

```mql5
int OnInit()
{
    if(!CheckInputs())             return INIT_PARAMETERS_INCORRECT;
    if(!RegisterAllSymbols())      return INIT_FAILED;
    if(!CreateAllIndicatorHandles()) return INIT_FAILED;
    EventSetTimer(60);
    return INIT_SUCCEEDED;
}
```

Appelé une fois au chargement de l'EA (ou au changement d'inputs / recompilation).

**Retours** :
- `INIT_SUCCEEDED` : EA actif
- `INIT_FAILED` : erreur transitoire
- `INIT_PARAMETERS_INCORRECT` : inputs invalides — terminal propose à l'utilisateur de modifier

## OnDeinit

```mql5
void OnDeinit(const int reason)
{
    EventKillTimer();
    for(int i=0;i<ArraySize(g_handles);i++)
        if(g_handles[i] != INVALID_HANDLE) IndicatorRelease(g_handles[i]);
}
```

`reason` est une valeur de `ENUM_DEINIT_REASON` (REASON_REMOVE, REASON_CHARTCHANGE,
REASON_PARAMETERS, REASON_RECOMPILE, REASON_CHARTCLOSE, REASON_ACCOUNT, etc.).

## OnTick

Doc : *"The OnTick() function is the handler for the NewTick event. It is generated
for Expert Advisors only when a new price tick is received for the symbol associated
with the chart"* (mql5docs).

```mql5
void OnTick()
{
    // PATTERN NewBar : ne pas réagir à chaque tick mais une fois par bar
    static datetime last_bar = 0;
    datetime current = iTime(_Symbol, PERIOD_M1, 0);
    if(current == last_bar) return;
    last_bar = current;

    // Ici on est en début de la bar M1 courante (la précédente vient de fermer)
    // Logique signal sur shift=1 (la bar fermée)
}
```

**Règles** :
- Tick uniquement pour le **symbole du chart attaché** — pas les autres
- Doit s'exécuter en moins de ~200ms (sinon ticks suivants peuvent être perdus)
- Le timing dépend du flux broker — ne pas se reposer dessus pour scheduling régulier

## OnTimer

Doc : *"The OnTimer() function is called when the Timer event occurs, which is
generated by the system timer only for Expert Advisors and indicators."*

```mql5
EventSetTimer(60);              // timer 1 minute (min 1 seconde)
EventSetMillisecondTimer(500);  // haute résolution si besoin (>1Hz)

void OnTimer()
{
    // Tâches déterministes : refresh macro_cache, recalcul vol global daily, monitoring DD
}
```

**Règles** :
- Indépendant des ticks — utile sur weekends ou marchés fermés
- Un seul timer actif à la fois (le dernier `EventSetTimer` écrase le précédent)
- `EventKillTimer()` dans `OnDeinit`

## OnTradeTransaction

Appelé pour chaque transaction du compte (ordre placé, modifié, exécuté, position ouverte/fermée).

```mql5
void OnTradeTransaction(const MqlTradeTransaction &trans,
                        const MqlTradeRequest &req,
                        const MqlTradeResult &res)
{
    if(trans.type == TRADE_TRANSACTION_DEAL_ADD)
    {
        // Un deal est apparu dans l'historique — typiquement un fill
        ulong deal_ticket = trans.deal;
        // Filtrer par magic, par symbole, etc.
    }
}
```

**Types de transactions clés** (`ENUM_TRADE_TRANSACTION_TYPE`) :
- `TRADE_TRANSACTION_DEAL_ADD` — nouveau deal (open ou close)
- `TRADE_TRANSACTION_ORDER_ADD` / `_UPDATE` / `_DELETE`
- `TRADE_TRANSACTION_POSITION` — modification de position (SL/TP)
- `TRADE_TRANSACTION_REQUEST` — résultat d'un OrderSend

## OnChartEvent

Pour interactions UI (rare en EA pur trading) :
```mql5
void OnChartEvent(const int id, const long &lparam,
                  const double &dparam, const string &sparam)
{
    if(id == CHARTEVENT_KEYDOWN) { /* lparam = code touche */ }
    if(id == CHARTEVENT_OBJECT_CLICK) { /* sparam = nom de l'objet */ }
}
```

## OnBookEvent

Market depth (book) — uniquement si on a appelé `MarketBookAdd(symbol)` au préalable.
Utile pour stratégies HFT/orderbook. Pas utilisé dans ce projet.

## Ordre d'appel

Un seul thread EA ; les handlers sont appelés séquentiellement. Si un tick arrive
pendant `OnTimer`, il est mis en file et `OnTick` est appelé après `OnTimer`.

## Contexte multi-event de notre projet

| Sleeve | Handler primaire | Action |
|--------|-----------------|--------|
| MR Macro | `OnTick` (NewBar M1) | Recalcul VWAP/BB, signal entry/exit, check time-stop |
| TS Momentum | `OnTimer` daily à 21:05 UTC | Recalcul EMA/RSI, signal entry/exit |
| RSI Daily | `OnTimer` daily à 21:05 UTC | Recalcul RSI(14), signal entry/exit |
| Vol-targeting global | `OnTimer` daily à 21:05 UTC | Recalcul σ21/σ63, set FX_GLOBAL_LEVERAGE |
| Macro refresh | `OnTimer` 1 min | Re-lit macro_cache.csv, ferme MR si stale |
| Circuit-breaker DD | `OnTick` + `OnTimer` | Check equity vs peak |
